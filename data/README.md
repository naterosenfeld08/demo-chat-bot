# data/

CSV, JSON, and other data files your app reads or writes.

- Keep sample or seed data small enough to commit.
- **Never commit real personal data**: not your classmates', not anyone's. If
  you collect anything from a user test, strip names first.
- Large files don't belong in git. If something is over a few megabytes, ask
  before adding it.

Delete this README once there's real data here.
