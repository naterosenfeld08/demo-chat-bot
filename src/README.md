# src/

Your application code.

- **static-web track:** `app.js`, `styles.css`, and any other JS/CSS. The page
  itself is `index.html` in the project root.
- **python-tool track:** your `.py` modules. Keep the entry point obvious.
  name it `app.py` or `main.py`.
- **other track:** whatever your language expects. Say so in `AGENTS.md` section 5.

Keep files small enough to read in one sitting. When one starts doing several
unrelated jobs, that's the signal to split it.

Delete this README once there's real code here.
